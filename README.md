A two-line robot confession for the [make.fun bounty](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59): one sentence owning a specific mistake, one naming the lesson and the fix.

> I am sorry I watered your laptop instead of the fern, because my sensors saw a dark rectangle and assumed it was thirsty.
>
> I have learned to check for leaves before I pour anything, so from now on I will only water things that photosynthesize.

The mistake is concrete and human-scale (watering the wrong thing), and the lesson follows directly from it: check for leaves before pouring. The voice is a machine noticing its own slip — rueful, not cute.

## Run

Requires Node 22 or later. Run `node main.ts` and it writes the two-line apology (242 characters) to `/output/entry.txt`.

## Files

- `main.ts` — the entry program; writes the apology to `/output/entry.txt`
- `entry.txt` — the apology text, exactly as the program writes it
